Storyline 360 production storyboard

Working title: Before you paste, classify.

Project name: Safe AI — the classify conversation

Audience: Knowledge workers on a distributed EU team. The conversation is a line manager and a remote staff member.

Business problem: People paste client data into public AI tools and share files on personal devices.

Required behaviour: Before any paste, prompt, or file share: name the data → approved tool, stripped example, or no AI → if unsure, stop and ask.

Length: 12–18 minutes. One conversation. Two variables. One scored check.

Visual: Module visual system PDF. 16:9. Paper #FFFFFF, ink #3B3B3B, do #DBE0DC, don’t #E8DED5, step #E6E6E6. Open Sauce One (body, buttons) and League Gothic (01 02 03 only). Player: paper, ink, accent as ink. No fake client logo.

Characters: Jordan (line manager). Alex (remote staff). First names only. No surnames. No photographs of real people unless Keith supplies them; use Storyline illustrated characters or empty caption bars until then.

Variables: classifiedCorrect (True/False, default False). askedIfUnsure (True/False, default False). ScorePercent (Number, default 0).

Player: Menu on. Seekbar off. Volume if no audio: hide. Closed captions off until audio exists. Keyboard tab order: heading, body, then buttons left to right.

Portfolio sample. Not a named employer. Ask-role on screen: “line manager or data-protection lead.”

How to read the table: “On-screen copy” is every word on the base slide and on each named layer. Do not add extra sentences in Storyline. “Slide format” is the layout to build.
