Module visual system.

Use this sheet in Rise and Storyline so every demo matches the job aid. Two faces. Five colours. No third look.

Colours — paste these hex values

Paper#FFFFFFPage, empty field, slide fill
Ink#3B3B3BTitles, body, icons, player chrome
Do#DBE0DCAllowed path, continue, correct
Don’t#E8DED5Stop path, incorrect, caution
Step#E6E6E601 / 02 / 03 tiles, neutral blocks

Colour groups meaning. It is not decoration. No teal, no cream stationery, no black #000, no red danger panel.

Type

Document name

Main title — Open Sauce One 600

01 object title — League Gothic

Body is Open Sauce One 400. Sentences never sit in League Gothic. Line spacing 1.5. One line of space under a block title.

Weights

Open Sauce One: 400, 500, 600 only. Not ExtraBold, not Black.

League Gothic: regular. Stand-in if the file is missing: Impact.

Do not use Poppins, Nunito, Outfit, Syne, Montserrat, or IBM Plex on these modules.

Set the theme once.

Do this on day one of the trial. Then build. Do not pick a new palette per screen.

Rise — theme colours

In Rise: Theme → colors. Map them like this:

Page / background #FFFFFF Headings and body #3B3B3B Accent / buttons #3B3B3B Block — allowed #DBE0DC Block — stop #E8DED5 Block — steps #E6E6E6

Upload Open Sauce One if the trial lets you add a font. If it does not, use the closest sans Rise already has for body, and keep League Gothic for 01 02 03 only when you can embed it. Do not switch to a decorative Rise template.

Storyline — slide and player

Slide fill #FFFFFF Text #3B3B3B Player / menu #3B3B3B on #FFFFFF Correct / continue fill #DBE0DC, text #3B3B3B Incorrect / stop fill #E8DED5, text #3B3B3B Neutral tiles #E6E6E6 Focus / selected 2 px ink outline, not a new colour

Install Open Sauce One and League Gothic on the Windows machine before the trial week. Storyline can use installed faces. Embed them on publish so the SCORM zip still looks right.

Layout (both tools)

  • Wide white margins. Do not fill the page.
  • Eyebrow (League Gothic) → large title (Open Sauce 600) → one-line deck.
  • Equal colour blocks for do / don’t. Line icons only. No stock photo, no fake logo.
  • Process as oversized 01 02 03 on equal step tiles. Short caption under each number.
