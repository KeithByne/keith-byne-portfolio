# Storyboard Master

Use this for every client and every portfolio module. Copy the blank Word file. Do not invent a company or a logo. The client supplies artwork.

**Formatting is locked. Content is not.** Change the words in the cells whenever the job needs it: company, project, aspect ratio, aim, notes, assets, format, screen copy, and interactions. Do not rename labels, move rows, change type sizes, fills, page size, or page breaks.

## Always produce two files

1. **Storyboard** — the full Word document.
2. **Brand Guideline ROM** — pages 1–2 only, PDF named `Company Name_Project Name.pdf`. Open it in a browser to pick colours into Rise 360 or Storyline 360.

## Page order

| Page | Layout | Content |
|------|--------|---------|
| 1 | A4 **portrait** | Block 01 written brand (no outer frame) |
| 2 | A4 **landscape** | Block 02 fonts and Block 03 colour scale (no outer frames) |
| 3 onwards | A4 **landscape** | Storyboard list: Rise **blocks**, then Storyline **scenes / slides / layers** |

A storyboard table is never split across two pages. If it would not fit, the whole table moves to the next page.

Do not repeat Block 01 on the storyboard pages. Storyboard tables keep cell frames. Information text is 14pt. Label text is 16pt bold, on the step fill `#E6E6E6`.

## Block 01 labels

The title bar is the title of that page. It is not a content row.

1. Title bar: Block 01 · Brand guideline (written)
2. One small row with no fill
3. Company
4. Project
5. Aspect Ratio
6. Project Aim
7. Alignment
8. Logo / artwork
9. Notes

## Storyboard table labels

Each block, scene, slide, or layer is one table, with a blank line between tables.

1. Assets
2. Format
3. Screen Copy
4. Interactions
