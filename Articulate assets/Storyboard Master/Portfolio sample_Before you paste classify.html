Block 01 · Brand guideline (written)
  
CompanyPortfolio sample
ProjectBefore you paste, classify.
Aspect Ratio16:9 HD (1920 x 1080)
Project AimA 10–18 minute habit module so remote EU knowledge workers classify data before any paste, prompt, or file share. Same habit in Rise 360 (blocks) and Storyline 360 (slides).
AlignmentLeft (all learner-facing text)
Logo / artworkClient supplies. Do not invent a mark.
NotesNot a named client. No logo. Line icons only; no stock photo. Named ask-role still unconfirmed; on-screen copy uses “line manager or data-protection lead.” Do not use Poppins, Nunito, Outfit, Syne, Montserrat, IBM Plex, teal, cream stationery, black #000, or a red danger panel. Public site chrome stays navy / Outfit / Syne; this sheet is for the learning artefacts only.
