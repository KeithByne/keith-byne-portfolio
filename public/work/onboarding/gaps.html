Where the gaps close.

Operations coordinator. “Now” stays blank until a real person starts. This sample does not invent a level.

Skill By day 90 Now How it closes
Handover The weekly handover goes out without a rewrite. At the start Line manager in days 1–30. Peer checks one from day 31.
Tools The shared tools are current. At the start Practice on the real tools. Peer from day 31.
Meetings They set and run the weekly meetings. At the start Shadow in week 1. Run one with a check in days 31–60. Own them by day 90.
Decisions They know which decisions are theirs. At the start Line manager in the first 30 days. A page for the list that repeats.
Remote days The week still moves on Monday, Thursday, and Friday. At the start A page for the repeatable task. A call when the task is new.
