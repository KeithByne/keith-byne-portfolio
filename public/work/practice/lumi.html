Practice — before Articulate

Lumi. One decision.

Install the free Lumi desktop app. Make one H5P branching scenario. Export SCORM 1.2. This is an activity inside a platform, not a course.

What you are learning

The tool stores choices and feedback. The zip adds a SCORM wrapper so an LMS can record completion. You are not designing a new story.

Build this

Start. A colleague asks you to “just drop this into ChatGPT and tidy it.” The file is a customer list with emails and contract values.

Choice A — correct. Confidential or personal data. I must not paste it into a public AI tool. Feedback: Stop. Emails and contract values stay off public AI. Redact, use an approved tool, or use no AI.

Choice B — wrong. Harmless working text. Public AI is fine. Feedback: That list is not harmless. Names, emails, and contract values are personal data. Take the careful path.

Clicks

  1. New content → Branching scenario.
  2. One start screen. Two choices. Each choice ends. Do not add more screens.
  3. File → Export → SCORM package.
  4. Upload the zip to your SCORM Cloud account. Launch it. Pick the wrong choice once, then the right one.

Leave Articulate shut. Do not add a second scenario.
