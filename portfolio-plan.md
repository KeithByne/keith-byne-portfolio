This is the map for the next 12 weeks. The homework **is** the portfolio.

You felt out of order because the cheat-sheet work kept pointing at a Rise module you have not built. That was the old calendar: *make the page, then write the course*. Backwards for someone still learning the trade.

**New rule:** think and write first. Make simple files next. Open time-limited accounts last, when you already know what you are going to build.

The Work page on the site can keep showing pieces in hiring-manager order. This file is **your build order**. They are allowed to differ.

# 1. Overview

## What you are becoming (90 days)

A remote European **instructional designer / learning experience designer / e-learning developer**. Later, if the artefacts exist, a corporate L&D manager application. Not a job offer by default.

You already run programmes, write materials, and ship software. What is new is **this industry’s production kit** and **the way they want work shown**: a short public sample of *one work habit*, not a university course.

## One topic, four finished things

Everything except the last piece is the **same work problem**:

> Remote staff paste client or staff data into public AI, or put files on personal drives.

You do not invent a client name. You do not invent “we cut leaks by 40%.”

| Finished thing | What it is in ordinary words | Tool | Expires? |
|----------------|------------------------------|------|----------|
| **A. Cheat sheet + 8 slides** | A desk page for the worker, and a 10-minute talk for the person who says yes | Canva + PowerPoint | No |
| **B. Short online module** | 10–15 minutes: name the data, take a path, one marked question | Articulate **Rise** | **Yes — 30-day trial** |
| **C. One conversation scene** | A manager talks to a staff member; the screen remembers choices | Articulate **Storyline** | **Same 30-day trial as B** |
| **D. 90-day onboarding outline** | A plan for bringing someone into a hybrid team — not a click-through course | Google Docs / Sheets | No |

A, B, and C share the Safe AI topic. D is a different artefact (L&D-manager evidence). You still write a short outline for D early, so the whole job is visible before you touch the trial.

## Why this order

1. **Paper first.** If you cannot say who, what is going wrong, and what they must *do*, software will not save you.  
2. **Scripts before screens.** Rise, the cheat sheet, the slides, and Storyline all get a written plan *before* you open Canva, and long before Articulate.  
3. **Free, no-clock tools in the middle.** Canva and PowerPoint teach layout without a countdown.  
4. **LMS once, with a dummy file.** You learn “upload, link, SCORM” on a PDF, not during a panic in week 6.  
5. **Articulate last among the course builds.** One 30-day login for Rise *and* Storyline. You only start it when every script is locked and you have already made A.  
6. **Applications last.** CV skill lines appear only when a public file exists.

# 2. Glossary

Read once. After that, the staged plan uses ordinary words, with the jargon in brackets the first time it matters.

## The job and the people

| Term | Meaning here |
|------|----------------|
| **Instructional designer (ID)** | Designs learning so people can *do* a job, not so they sit through content. |
| **Learning experience designer (LXD)** | Same family; more emphasis on the path the person takes on screen. |
| **e-learning developer** | Builds the actual module in tools such as Rise or Storyline. |
| **L&D** | Learning and Development — the company function that owns training. |
| **Hiring manager** | The ID/LXD/L&D person who will scan your site in a few minutes. |
| **Audience** | Who a piece is for. Desk page: the remote worker. Slides: the person who approves. |
| **Stakeholder** | Someone with power or risk in the decision (manager, L&D, legal). |
| **Learner** | The person taking the module. Never call them a student on this portfolio. |

## How the work is planned

| Term | Meaning here |
|------|----------------|
| **Action mapping** (Cathy Moore) | Plan on one page: who, what is going wrong at work, what they must do, how you would notice. A course is only for the bit a page cannot fix. |
| **Action map** | That one-page plan. Yours is not written yet. It is Stage 1. |
| **Business problem** | What is going wrong for the company (risk, leaks), not “they lack knowledge.” |
| **Required behaviour** | What they must *do*. Here: classify data, then take the allowed path. |
| **Moment of need** | The 30 seconds before a paste, a prompt, or a file share. |
| **Metric** | How you would tell it worked. Count bad pastes. Do not invent a percentage. |
| **Performance support** | Help at the desk while they work. The cheat sheet is this. |
| **Job aid** | Industry name for that cheat sheet. |
| **Stakeholder deck** | The 8 slides for the yes-meeting. |
| **Storyboard** | The written script before design: headings, exact sentences, click paths. |
| **Case study / case** | A portfolio write-up: problem, limit, design choice, link to the live file. |
| **Artefact** | A finished thing a hiring manager can open. |

## The Safe AI topic

| Term | Meaning here |
|------|----------------|
| **Classify** | Name the kind of data before you paste: public / internal / personal / customer. |
| **GDPR** | EU personal-data law. Names, emails, staff files, customer lists count. |
| **Public AI** | ChatGPT and similar, where prompts can leave the company. |
| **Approved tool** | Software the company has already allowed. We do not invent a brand list. |
| **Redact** | Remove or fake sensitive bits before using AI. |
| **DPO** | Data Protection Officer. Who people ask if unsure is still [TO CONFIRM]. |
| **Branch** | The module splits: right choice → careful path; wrong choice → a correction; then both meet again. |
| **Scored check** | One marked question. Rise has exactly one. |

## The software (learn in this order)

| Term | Meaning here | Clock? |
|------|----------------|--------|
| **Canva** | Simple layout tool for the one-pager. Free tier. | No |
| **PowerPoint** | The 8 slides. You likely already have it. | No |
| **Figma** | Optional: boxes-on-a-page drawing of the Rise path. Free. | No |
| **LMS** | Learning Management System — the school/company platform that *hosts* courses (Moodle, etc.). Name the one you already run, when you can. | — |
| **SCORM** | A zip format so a module will *play inside* an LMS. Ads ask for **SCORM 1.2**. | — |
| **SCORM Cloud** | A free host so an employer can click a demo. Use it for a dummy PDF first, then for real modules. | Free account, not a 30-day authoring trial |
| **Articulate 360** | Paid suite. **30-day trial, no card.** Contains Rise and Storyline. **One clock for both.** | **Yes — 30 days** |
| **Rise 360** | Form-based e-learning. Faster. Case B. | Inside that trial |
| **Storyline 360** | Timeline, buttons, memory of choices (“variables” / “states”). Case C. Senior ads often require it. | Inside that trial |
| **Review 360** | Articulate’s share link. **It dies with the trial.** Always keep a Netlify or SCORM Cloud copy. |
| **Netlify** | Free web host for the HTML export after the trial ends. | No |
| **Synthesia / HeyGen / Vyond** | AI or cartoon video. Skip for 90 days unless you later choose one 60-second clip with a *free* editor. | Do not open a video trial early |

## Words you will see on adverts (recognise, do not claim)

Workday Learning, Docebo, 360Learning, LearnUpon, Rise Up — other LMS product names. You need **one** real upload (yours or SCORM Cloud), not seven logos on the CV.

# 3. Staged plan

Software gets more specialised as you go. **Nothing with a 30-day clock until Stage 5.**

```
Stage 1  Think (action map)           ← you are here next

```

## Stage 1 — Think (no new software)

**Week 1. Goal:** One page that states the job. If this is weak, every later file is decoration.

**Do**

1. Read this plan and the glossary.  
2. Fill any `[TO CONFIRM]` on `cv.md` / `cover-letter.md` you already know.  
3. Read Cathy Moore’s free Action Mapping articles.  
4. Write `portfolio/safe-ai-action-map.md` with four lines only:

   - **Who:** knowledge workers on a distributed EU team (not teachers).  
   - **What is going wrong:** pasting client/staff data into public AI; putting files on personal drives.  
   - **What they must do:** classify → approved tool, stripped example, or no AI → ask if unsure.  
   - **How we would notice:** fewer unapproved pastes / fewer personal-drive shares. No percentage.

**Do not:** Canva, PowerPoint, Figma, SCORM Cloud, Articulate.

**Unlock when the action-map file exists:** “Action mapping / performance-first design” on the skills log — still not on `cv.md` until you are happy it is a real file in the repo.
