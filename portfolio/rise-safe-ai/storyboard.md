# Rise module storyboard

**Working title:** Safe AI and data handling for remote enterprise teams  
**Audience:** Knowledge workers on a distributed EU team (not teachers).  
**Business problem:** People paste client data into public AI tools and share files on personal devices, creating GDPR and leak risk.  
**Required behaviour:** Before using any AI tool or sharing a file, the person classifies the data and chooses the approved path.  
**Metric (for the case-study page):** Fewer unapproved AI pastes / fewer personal-drive shares. We will not invent a percentage.  
**Length:** 10–15 minutes. One scored check. One branch.

Do not start the Articulate trial until Week 5. Build from this script.

## Course map

1. Welcome and why this matters (no branch)
2. Classify the data (decision)
3. **Branch A — confidential / personal data** (correct caution)
4. **Branch B — public / already-approved data** (speed path)
5. Both paths rejoin: approved tools and red lines
6. Scenario check (scored)
7. Job aid reminder and close

## Screen copy

### 1. Welcome

**Heading:** Before you paste, classify.  
**Body:** Remote work is fast. Public AI tools and personal drives are faster still. This module is not a policy lecture. It is the 30-second habit your team needs before client text, staff data, or unpublished files leave an approved system.  
**Continue:** Start with a live decision.

### 2. Classify (branch point)

**Heading:** A colleague asks you to “just drop this into ChatGPT and tidy it.”  
**Body:** The file is a customer list with emails and contract values. What is it?  
**Choice A:** Confidential or personal data — I must not paste it into a public AI tool. → **Branch A**  
**Choice B:** Harmless working text — public AI is fine. → **Branch B**  
*(Choice B is the distractor. The list is personal and commercial data.)*

### 3. Branch A (correct)

**Heading:** Stop. This is personal and commercial data.  
**Body:** Emails and contract values are personal data and business-confidential. Public AI tools may store prompts. Your approved path is: redacted example, internal approved tool, or no AI.  
**Continue:** See the red lines.

### 4. Branch B (incorrect — coach, then rejoin)

**Heading:** That list is not harmless.  
**Body:** Names, emails, and contract values are personal data under GDPR and confidential to the company. Public AI is the wrong path. You have not failed the module. You now take the same red-line screen as everyone else.  
**Continue:** See the red lines.

### 5. Rejoin — red lines

**Heading:** Three checks before any AI or file share  
1. What data is this? (public / internal / personal / customer)  
2. Is this tool on the approved list?  
3. If I am unsure, I do not paste — I ask [TO CONFIRM: role, e.g. DPO / line manager].  
**Continue:** Try one scenario.

### 6. Scored check

**Stem:** You are drafting a process note. You want AI to improve the English. The note includes one customer email address.  
**Correct:** Remove the email (or replace with a fake), then use the approved tool.  
**Incorrect:** Paste the whole note into a public tool because it is “just one email.”  
**Incorrect:** Put the file on a personal Google Drive so a contractor can edit it overnight.  
**Feedback (correct):** Redact first, then use an approved tool.  
**Feedback (incorrect):** One email is still personal data. Personal drives are not the contractor workaround.

### 7. Close

**Heading:** The habit is the course.  
**Body:** Classify → approved tool or no AI → ask if unsure. Take the one-page job aid (Case study A) and keep it next to your desktop.  
**End.**
