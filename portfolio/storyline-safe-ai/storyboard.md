# Storyline 360 module storyboard

**Working title:** Before you paste, classify.  
**Project name:** Safe AI — the classify conversation  
**Audience:** Knowledge workers on a distributed EU team. The conversation is a line manager and a remote staff member.  
**Business problem:** People paste client data into public AI tools and share files on personal devices.  
**Required behaviour:** Before any paste, prompt, or file share: name the data → approved tool, stripped example, or no AI → if unsure, stop and ask.  
**Length:** 12–18 minutes. One conversation. Two True/False variables. One scored check.  
**Visual:** Module visual system. 16:9. Paper `#FFFFFF`, ink `#3B3B3B`, do `#DBE0DC`, don’t `#E8DED5`, step `#E6E6E6`. Open Sauce One and League Gothic. No fake client logo.  
**Characters:** Jordan (line manager). Alex (remote staff). First names only.  
**Variables:** `classifiedCorrect` (True/False, default False). `askedIfUnsure` (True/False, default False). `ScorePercent` (Number, default 0).  
**SCORM:** Sharable Content Object Reference Model (SCORM) 1.2. Complete when Finish is clicked. Score is `ScorePercent`.

The production table (every on-screen word, interactions, slide format) lives in [Articulate assets](../../Articulate%20assets/Articulate%20assets.md) as Word and HTML. Do not add extra sentences in Storyline 360.
