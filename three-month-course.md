# 12-week skills course

The homework **is** the portfolio. Time the Articulate trial for **weeks 5–8** only (30 days).

## Weeks 1–4 — public home, method, no trial

**Week 1**
- Fill every `[TO CONFIRM]` you already know on [cv.md](cv.md) and [cover-letter.md](cover-letter.md).
- Match LinkedIn headline to the CV title.
- Study Cathy Moore’s Action Mapping (free). Write one action map for the Rise topic (audience, business metric, required behaviour).
- Unlock log: action mapping.

**Week 2**
- Case study A: one-page Canva job aid + 8-slide PowerPoint for the same audience (remote teams, safe AI / data handling).
- Put both on the Wix index (or a temporary Google Drive link until Wix exists).
- Unlock log: Canva, PowerPoint.

**Week 3**
- Storyboard and accessibility notes for the Rise module (use [portfolio/rise-safe-ai/storyboard.md](portfolio/rise-safe-ai/storyboard.md)).
- Optional Figma wireframe of the two branch paths.

**Week 4**
- Create SCORM Cloud (and name the LMS Keith already uses).
- Upload a simple package or PDF “course.” Write 10-step publish notes in this repo.
- Unlock log: named LMS.

## Weeks 5–8 — Articulate trial, two hero builds

**Week 5–6**
- Start the Articulate 360 trial.
- Build Case study B in Rise: *Safe AI and data handling for remote enterprise teams* (~10–15 minutes, one branch, one scored check).
- Host on SCORM Cloud and/or web export.
- Unlock log: Rise + URL.

**Week 7–8**
- Case study C in Storyline: one manager conversation with variables/states.
- Publish SCORM 1.2 + HTML5. Host on SCORM Cloud and Netlify.
- Unlock log: Storyline + SCORM + URL.
- Write a case-study page for A, B, and C (problem, constraint, design choice, link).

## Weeks 9–12 — L&D stretch and applications

**Week 9–10**
- Case study D: 90-day hybrid onboarding framework + skill-gap sheet (Google Docs/Sheets).
- Unlock log: needs analysis / onboarding (needed before L&D Manager applications).

**Week 11**
- Optional 60-second walkthrough of the Rise module.
- Wix index complete: About, four case studies, contact, CV download.

**Week 12**
- Apply: Jobgether, Remote Rocketship, Working Nomads, LinkedIn.
- Search titles: Instructional Designer, eLearning Developer, Learning Experience Designer, Digital Learning Designer.
- Use L&D Manager only where the advert is design-heavy or player-coach.
- Tailor [cover-letter.md](cover-letter.md) per advert. Name one live artefact.

## Done (end of week 12)

Four public artefacts, Wix index, CV that matches the artefacts, applications sent. Not a job offer, and not an L&D Manager title by default.
