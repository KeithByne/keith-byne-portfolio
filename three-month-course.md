# 12-week skills course

The homework **is** the portfolio.

**Read [portfolio-plan.md](portfolio-plan.md) first** — overview, glossary, and why the order changed. This file is the week checklist only.

**Rule:** scripts before screens. Canva and PowerPoint before Articulate. The 30-day Articulate trial starts in **week 6**, not before.

## Weeks 1–2 — think and write (no production software)

**Week 1 — Stage 1**
- Read [portfolio-plan.md](portfolio-plan.md).
- Fill every `[TO CONFIRM]` you already know on [cv.md](cv.md) and [cover-letter.md](cover-letter.md).
- Match LinkedIn headline to the CV title.
- Study Cathy Moore’s Action Mapping (free). Write [portfolio/safe-ai-action-map.md](portfolio/safe-ai-action-map.md) (who, problem, required action, how you would notice).
- Unlock log: action mapping.

**Week 2 — Stage 2**
- Lock the Rise script: [portfolio/rise-safe-ai/storyboard.md](portfolio/rise-safe-ai/storyboard.md) (plain-English pass if it is still opaque).
- Lock the cheat-sheet + slides script: [portfolio/job-aid-safe-ai/storyboard.md](portfolio/job-aid-safe-ai/storyboard.md).
- Write the Storyline script (one manager conversation, same Safe AI habit) before any trial.
- One-page outline of the later 90-day onboarding artefact.
- Optional: Figma or paper drawing of the Rise path.
- **Do not** start Articulate. **Do not** start Canva until A and B scripts are locked.

## Weeks 3–5 — easy tools, then dummy hosting

**Week 3 — Stage 3 (Canva)**
- **Canva Free** account is already open (22 Sep 2026). No time limit. Do not start Pro.
- One-page cheat sheet from the locked script.
- Export PDF + PNG. Public Drive (or site) link.
- Unlock log: Canva, once the URL exists.

**Week 4 — Stage 3 (PowerPoint)**
- 8-slide talk from the locked script. Slide 6 = PNG of the cheat sheet.
- Public link.
- Unlock log: PowerPoint job aids and stakeholder decks.

**Week 5 — Stage 4 (LMS plumbing)**
- **[SCORM Cloud](https://cloud.scorm.com/)** account is already open (free Trial; no time limit). Product: [Rustici SCORM Cloud](https://rusticisoftware.com/products/scorm-cloud/). Pricing: [trial limits](https://rusticisoftware.com/products/scorm-cloud/pricing/). Guide: [getting started](https://cloud.scorm.com/docs/user-guide/getting-started/). Do not add a card.
- Upload a simple package or the job-aid PDF as a stand-in course. Write 10-step publish notes in this repo.
- Unlock log: SCORM Cloud (academy LMS is already named on the CV as Google Classroom).
- **Still do not** start Articulate.

## Weeks 6–9 — Articulate trial only (two hero builds)

Start the Articulate 360 trial on **day 1 of week 6**. Same 30-day login for Rise and Storyline.

**Weeks 6–7 — Stage 5 (Rise)**
- Build Case B from the locked Rise script (~10–15 minutes, one branch, one scored check).
- Host on SCORM Cloud and/or web export. Do not rely on Review 360 as the portfolio URL.
- Unlock log: Rise + URL.

**Weeks 8–9 — Stage 5 (Storyline)**
- Build Case C from the locked Storyline script (variables/states).
- Publish SCORM 1.2 + HTML5. Host on SCORM Cloud and Netlify.
- Unlock log: Storyline + SCORM + URL.
- Write case-study paragraphs for A, B, and C (problem, constraint, design choice, link).

## Weeks 10–12 — L&D stretch and applications

**Weeks 10–11 — Stage 6**
- Case D: 90-day hybrid onboarding framework + skill-gap sheet (Google Docs/Sheets), from the week 2 outline.
- Unlock log: needs analysis / onboarding (needed before L&D Manager applications).
- Optional 60-second walkthrough of the Rise module (CapCut or DaVinci Resolve — free). Skip Synthesia/HeyGen unless you later choose that on purpose.

**Week 12 — Stage 7**
- Site index complete: four case write-ups, contact, CV download.
- Apply: Jobgether, Remote Rocketship, Working Nomads, LinkedIn.
- Search titles: Instructional Designer, eLearning Developer, Learning Experience Designer, Digital Learning Designer.
- Use L&D Manager only where the advert is design-heavy or player-coach.
- Tailor [cover-letter.md](cover-letter.md) per advert. Name one live artefact.

## Done (end of week 12)

Four public artefacts, this site as the index, a CV that matches those artefacts, and applications going out. Not a job offer, and not an L&D Manager title by default.
